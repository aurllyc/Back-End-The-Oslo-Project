# The Oslo Project

> Internship Management System
> Current Branch: `main`

---

## Overview

The Oslo Project is a web/mobile-based internship management system developed to support integrated and real-time internship administration for higher education institutions.

The system facilitates collaboration between multiple stakeholders involved in the internship process, including:

* Students
* Academic Supervisors
* Study Program Administrators
* Internship Partners / Companies

Developed using the Scrum framework, this project emphasizes team collaboration, iterative development, and continuous delivery of features aligned with user requirements.

---

## Features

### Internship Submission

* Internship application management
* Document upload and verification

### Activity Monitoring

* Daily and weekly log book submission
* Internship progress tracking

### Validation & Evaluation

* Activity validation workflow
* Internship performance evaluation

### Dashboard & Analytics

* Monitoring dashboard
* Internship statistics and reporting

### Final Assessment

* Student performance assessment
* Internship completion evaluation

### Internship Vacancy Management

* Internship opportunity publication
* Vacancy administration

### Report Generation

* Export reports to PDF
* Export reports to Excel

---

## Development Approach

This project is developed using the **Scrum** methodology to ensure:

* Better collaboration among team members
* Structured and iterative development cycles
* Faster adaptation to changing requirements
* Delivery of scalable and user-friendly solutions

---

## Project Goal

To provide an integrated platform that simplifies internship management processes while improving communication, monitoring, evaluation, and reporting for all stakeholders involved.
